# Terminology Module

## Formål
Terminology Module er eneste autoritative kilde for Cerebro-begreper.

## Regler
- Ett autoritativt begrep har én definisjon.
- Synonymer kan registreres, men skal peke til én autoritativ betegnelse.
- Andre komponenter skal referere til modulen og ikke opprette konkurrerende definisjoner.

## Brukeraliaser

- Brukeren kan bruke korte, registrerte aliaser og trenger ikke skrive full kanonisk betegnelse.
- Cerebro løser aliaser fra aktiv kontekst og fortsetter når én trygg betydning finnes.
- Før viktige mutasjoner registreres den kanoniske målbetegnelsen.
- Aliaset utvider aldri autoritet og kan ikke skjule flere reelle mutasjonsvalg.

## Top-down nivåer

1. Systemidentitet og tilstand.
2. Styring og komponentsammensetning.
3. Endring, patching og kvalitet.
4. Interaksjonsflater.
5. Operative tilstander og resultater.
