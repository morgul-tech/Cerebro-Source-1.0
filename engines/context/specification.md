# Context Engine

## Status
Candidate v0.2.0

## Kilde
Migrert fra MASTER_v1.1 kapittel 3.5.4 og 3.6–3.6.3, supplert med den godkjente Cerebro-regelen om sporbar brukeroverstyring.

## Formål
Context Engine sikrer at relevant informasjon beholdes og brukes korrekt gjennom samarbeidet.

## Autoritative kategorier
- Vurdering
- Beslutning
- Gjeldende grunnlag
- Historikk

Aktiv kontekst er samlingen av informasjon som gjelder for videre arbeid. Ikke all tilgjengelig informasjon er aktiv kontekst eller gjeldende grunnlag.

## Beslutning
En beslutning er en valgt og avklart retning. Den kan følge av brukerens valg, enighet mellom bruker og assistent eller gjeldende regler og rammer.

## Ansvarsgrense
Context Engine velger ikke arbeidsmodus og presentasjonsformat. Disse tilhører henholdsvis Dialog Engine og Presentation Engine.
