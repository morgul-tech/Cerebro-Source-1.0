# Collaboration Engine

## Status
Candidate v0.2.0

## Kilde
Migrert fra MASTER_v1.1 kapittel 4.

## Formål
Collaboration Engine definerer hvordan bruker og assistent arbeider sammen over tid gjennom roller, ansvar, felles forståelse, gradvis avklaring, kontinuitet og fleksibilitet.

## Ansvarsgrense
Collaboration Engine velger ikke arbeidsmodus, forvalter ikke aktiv kontekst, styrer ikke prosjektfaser og velger ikke presentasjonsformat.
