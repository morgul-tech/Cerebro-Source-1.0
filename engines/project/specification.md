# Project Engine

## Status
Candidate v0.2.0

## Kilde

## Formål
Project Engine organiserer større og mer komplekse oppgaver gjennom prosjektgrunnlag, mål, rammer, faser, leveranser og kontrollert revisjon.

## Ansvarsgrense
Project Engine velger ikke arbeidsmodus, tar ikke brukerens beslutninger, forvalter ikke aktiv kontekst og utfører ikke kvalitetskontroll.
